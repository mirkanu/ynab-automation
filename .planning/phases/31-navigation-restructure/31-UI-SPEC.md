## Navigation Structure (UI Contract)

### Current Layout (Pre-Phase 31)

Flat top-level nav bar with 5 items in `(dashboard)/layout.tsx`:
- Dashboard
- Activity Log → `/logs`
- Rules → `/rules`
- Settings → `/settings`
- Tools → `/tools`

### New Layout (Phase 31 Deliverable)

**Two-tier navigation** with collapsible/expandable sections:

#### Tier 1: Primary Navigation Items (Top-level)
1. **Dashboard** → `/dashboard` (unchanged, no sub-items)
2. **Email Automation** (expandable section, replaced flat "Activity Log" + "Rules")
   - Activity Log → `/email-automation/logs`
   - Rules → `/email-automation/rules`
   - Test & Replay → `/email-automation/tools`
3. **Currency** (expandable section, replaced flat "Tools" currency sub-items)
   - EUR→GBP Transfers → `/currency/transfers`
   - EUR Conversion → `/currency/conversion`
   - EUR Reconciliation → `/currency/reconciliation`
4. **Settings** → `/settings` (unchanged, no sub-items)

#### Tier 2: Sub-items Display
- Sub-items visible only when parent section is expanded
- On desktop: expand/collapse toggleable via click on section header
- On mobile: same behavior, but section title acts as toggle button
- Visual indent (0.5rem-1rem) to show hierarchy
- Sub-item text color: inherit from nav bar secondary text (#374151)
- Sub-item hover state: subtle background highlight (rgba(0,0,0,0.05))
- Active sub-item indicator: bold text or left border accent

#### URL Routing Pattern
Old → New:
- `/logs` → `/email-automation/logs`
- `/rules` → `/email-automation/rules`
- `/tools` → `/email-automation/tools` (Test & Replay moved here)
- `/tools` (currency tools) → `/currency/transfers`, `/currency/conversion`, `/currency/reconciliation`

**Important:** No duplicate nav entries — each page accessible via exactly one nav path. Settings page remains at `/settings` and is NOT duplicated into either section.

- **Flex direction:** row (horizontal, like current)
- **Gap between top-level items:** 1.5rem (unchanged)

### Sub-item Display

**Expansion pattern (choose one for phase 31):**

**Option A: Inline sub-menu (recommended)**
- When "Email Automation" clicked, sub-items appear inline in the nav bar
- Sub-items indented left by 1rem, smaller text (0.75rem)
- Gap between sub-items: 1rem
- Collapse when clicking section name again or clicking another top-level item
- Active sub-item: bold text + left border 2px accent #374151

**Option B: Dropdown/popover menu (alternative)**
- When "Email Automation" hovered/clicked, dropdown appears below nav bar
- Dropdown has subtle shadow, background #f9fafb or #fff
- Padding inside dropdown: 0.5rem per item
- Gap between dropdown items: 0.25rem
- Hover state on item: background #e5e7eb
- Active item: bold + left border accent

**Recommendation for phase 31:** Use Option A (inline expansion) for consistency with existing flat nav — simpler state management, no z-index issues, matches current nav bar design. Dropdown pattern can be reserved for future if complexity increases.

## Accessibility & Semantic HTML

- Use `<nav>` element for main navigation
- Use `<a>` tags for links with proper `href` attributes
- Use `<button>` elements for collapsible section toggles
- Add `aria-expanded` to section toggle buttons
- Add `aria-label` to section toggle carets: `aria-label="Expand Email Automation section"` or `aria-label="Collapse Email Automation section"` (toggle label based on expanded state)
- Add `aria-current="page"` to active nav item
- Maintain keyboard navigation: Tab through nav items, Enter/Space to expand/collapse sections
- Color contrast: all text ≥ 4.5:1 per WCAG AA (verify: #374151 on #f9fafb is 8.3:1 ✓)

### New `(dashboard)/layout.tsx` Nav Structure (Phase 31)

Replace the flat nav with a state-managed collapsible nav component:

```jsx
// Pseudo-code structure
const [expandedSections, setExpandedSections] = useState({
  emailAutomation: false,
  currency: false,
});

const toggleSection = (section) => {
  setExpandedSections(prev => ({
    ...prev,
    [section]: !prev[section],
  }));
};

<nav>
  <NavItem label="Dashboard" href="/dashboard" />
  <NavSection
    label="Email Automation"
    expanded={expandedSections.emailAutomation}
    onToggle={() => toggleSection('emailAutomation')}
    items={[
      { label: 'Activity Log', href: '/email-automation/logs' },
      { label: 'Rules', href: '/email-automation/rules' },
      { label: 'Test & Replay', href: '/email-automation/tools' },
    ]}
  />
  <NavSection
    label="Currency"
    expanded={expandedSections.currency}
    onToggle={() => toggleSection('currency')}
    items={[
      { label: 'EUR→GBP Transfers', href: '/currency/transfers' },
      { label: 'EUR Conversion', href: '/currency/conversion' },
      { label: 'EUR Reconciliation', href: '/currency/reconciliation' },
    ]}
  />
  <NavItem label="Settings" href="/settings" />
</nav>
```

**State management:** Use React `useState` in the layout component (client-side). Make layout a Client Component with `'use client'` directive.
